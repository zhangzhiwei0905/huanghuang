# 压缩小程序候场顶部栏

## Goal

降低好友房候场页面顶部栏的视觉高度，让房间号、连接状态和操作按钮占用更少的横屏空间，把更多高度留给牌桌与玩家区域，同时保持信息清晰和操作可靠。

## Background

- 当前候场顶部栏位于 `apps/miniprogram/src/pages/room/index.tsx:419`，包含离开、房间号、底分、连接状态、复制房号、分享以及房主的解散按钮。
- `.lobby-toolbar` 当前高度为 `50px + safe-area-inset-top`，`.lobby-toolbar__button` 的可视高度和点击高度均为 44px。
- 小程序横屏规范要求关键操作保留至少 44px 的可靠触控区域，因此不能通过直接缩小点击区域来换取视觉紧凑。
- 顶部错误提示当前定位在工具栏下方，压缩顶部栏时必须同步保持提示位置正确。

## Requirements

### R1 压缩顶部栏视觉高度

- 候场顶部栏的主体高度从当前 50px 收敛到约 44px，不包括设备顶部安全区。
- 房间号仍作为顶部栏的信息主视觉；“好友房”、底分和连接状态继续完整显示且保持单行。
- 顶部栏左右内边距和元素间距同步收紧，但不得侵入横屏刘海或右侧安全区。

### R2 缩窄按钮但保持触控可靠

- 离开、复制房号、分享、解散按钮的视觉胶囊高度缩小到约 34–36px。
- 每个按钮的实际点击区域继续保持至少 44px 高，避免真机横屏下难以点击。
- 按钮文字不得换行；普通、分享和危险操作的视觉层级继续可辨认。

### R3 保持布局和行为

- 不改变离开、复制、分享、解散、底分或连接状态逻辑。
- 房主与普通成员两种按钮组合都必须在常见手机横屏宽度内完整显示。
- 顶部错误提示继续出现在工具栏下方，不被压缩后的栏位遮挡。
- 页面继续保持单屏、无新增滚动条或内容裁切。

## Acceptance Criteria

- [x] 候场顶部栏主体高度明显低于当前版本，并为牌桌区域释放垂直空间。
- [x] 房间号、底分和连接状态保持单行、清晰且无遮挡。
- [x] 离开、复制房号、分享、解散按钮的可视高度约为 34–36px。
- [x] 所有顶部按钮仍保留至少 44px 的点击高度和正常按压反馈。
- [x] 房主与普通成员视图均无按钮换行、溢出或安全区侵入。
- [x] 顶部错误提示位置正确，页面无新增滚动条。
- [x] 小程序类型检查、生产构建、格式检查和微信开发者工具 11352 截图验证通过。

## Out of Scope

- 修改候场玩家座位、中央等待区或准备按钮。
- 修改实战牌桌顶部信息胶囊。
- 修改房间协议、服务端接口或任何房间行为。
- 上传新的体验版或正式发布小程序。
