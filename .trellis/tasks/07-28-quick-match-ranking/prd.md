# 快速匹配与竞技段位

## Goal

为已绑定微信的真实账号提供一键四真人快速匹配，并把长期竞技段位、保护卡和竞技成就作为数据库权威数据持久化。竞技数据必须与房间牌桌分、未来可充值金币完全分离，且所有结算可审计、幂等、可恢复。

## Background

- 当前微信 `openid` 会复用稳定的 `anonymous_sessions.id`，可作为竞技资料账号主键。
- 当前 `RoundPlayer.score` 只是房间内零和牌桌分，不能作为账号段位或钱包余额。
- 当前仅有 `FRIEND` 与 `BOT` 房型，没有匹配队列；服务部署模型是单实例进程、SQLite WAL 和内存房间投影。
- 快速匹配首期不建立金币钱包、充值、消费或玩家间可充值资产转移。

## Requirements

### R1. Match eligibility and queue

- 快速匹配只允许 `wechatLinked=true` 的账号加入。
- 同一账号最多拥有一条队列记录或一场未结束竞技比赛。
- 匹配仅组成四名真人，不补机器人，不需要匹配确认、房间等待或准备。
- 使用统一竞技配置：底分 2、真人回合 20 秒、托管沿用服务端保守策略。
- 段位距离窗口：0–10 秒为 2 级、10–20 秒为 5 级、20–40 秒为 10 级、40 秒后全服。候选必须相互接受；同等候选优先等待最久、再优先段位距离最近。
- 排队可取消；断线保留 10 秒，恢复后保留原排队时间，超时自动取消。
- 匹配成功必须原子删除四条队列记录、创建比赛记录和竞技房，并随机分配座位后直接开局。

### R2. Competitive room lifecycle

- `MATCH` 房禁止普通加入、设置变更、添加机器人、聊天、邀请和房主解散。
- 开局后退出或断线只将原账号座位切为托管，不替换座位；重连可接管，原账号仍正常结算。
- 每次匹配只打一小局。胡牌或流局后不自动续局。
- 结算页提供“继续匹配”和“返回大厅”；个人确认结果不依赖其他玩家。
- 冷启动必须能恢复排队、进行中比赛或尚未确认的本人结算。

### R3. Rank model

- 顺序为黑铁、青铜、白银、黄金、铂金、钻石、星耀、雀神。
- 前七个大段各有 `Ⅴ、Ⅳ、Ⅲ、Ⅱ、Ⅰ`；新账号从黑铁Ⅴ开始。
- 连续级数 `0..34` 映射黑铁Ⅴ到星耀Ⅰ；`35` 映射雀神1级，之后无限递增。雀神1级可降回星耀Ⅰ，黑铁Ⅴ封底。
- 合法倍率 `1/2/4/8/16/32/64x` 分别对应 `1/2/3/4/5/6/7` 级。
- 赢家倍率为胡型倍率 × 来由倍率 × 赢家放赖倍率；每名输家按自己的权威胡牌支付额 ÷ 底分得到实际赔付倍率。杠分和牌桌净分不参与段位换算。
- 流局时四人段位不变，保护卡不消耗。

### R4. Protection

- 黑铁、青铜、白银败局免降且不消耗保护卡。
- 黄金及以上先按每张抵消 1 级自动消耗保护卡，再应用剩余降级。
- 首次进入每个更高大段时发 2 张保护卡；以历史最高大段保证每个大段终身只发一次。跨越多个新大段时逐个发放，初始黑铁不发。

### R5. Competitive achievements

仅快速匹配四真人局中，服务端首次接受以下权威动作时累计：

- 明杠 `EXPOSED_KONG`
- 碰亮牌 `INDICATOR_PONG_KONG`
- 补杠 `ADDED_KONG`
- 暗杠 `CONCEALED_KONG`

动作事实与房间状态同事务提交，并以服务端回合和版本去重。好友房、人机房及纯机器人动作不累计。流局前已完成动作仍累计。

### R6. Public and private profile data

- 首页展示本人当前段位。
- 玩家头像和名字均可打开资料卡，公开展示段位与四项竞技成就。
- 保护卡余额只对本人展示；不得下发 `openid`、token 或内部会话凭据。
- 原“积分”文案改成“本局牌桌分”，避免与段位混淆。

### R7. Authority and operations

- 协议层拥有输入 schema 和 DTO；服务端拥有匹配、段位、成就和结算权威，客户端不重算。
- 成功命令必须把房间快照、请求幂等结果、成就事实和首次终局结算原子提交。
- 首期明确只支持单服务实例；多实例需要另行引入共享锁、Socket adapter 和房间单写者机制。
- 数据库迁移只能增量新增，不破坏既有微信会话、好友房与人机房。

## Acceptance Criteria

- [x] 未绑定微信账号不能排队；重复入队、取消和恢复均返回稳定权威状态。
- [x] 四名符合动态窗口的真人被原子组队，直接进入固定配置的 `MATCH` 对局。
- [x] 掉线 10 秒边界、排队取消、多 Socket 和开局后托管均有测试覆盖。
- [x] 全部倍率、段位边界、跨段奖励、低段免降、保护卡抵扣、黑铁下限和雀神回退通过纯单元测试。
- [x] 每个竞技终局只结算一次；重试、动画完成、重启或重连不会重复升降级。
- [x] 四类竞技成就每个权威动作只累计一次，其他房型不累计。
- [x] 小程序可从首页排队、取消、直接进入牌桌，并在结算后继续匹配或返回大厅。
- [x] 冷启动可恢复排队、比赛或本人待确认结算。
- [x] 资料卡公开段位和四项成就，保护卡只对本人可见，牌桌分文案无歧义。
- [x] `pnpm lint`、`pnpm typecheck`、`pnpm test`、`pnpm build` 和小程序生产构建通过。

## Out of Scope

- 金币余额、充值、消费、提现和支付回调。
- 多服务实例匹配与房间执行。
- 赛季、排行榜、举报、信誉处罚和额外逃跑扣分。
- Web 端快速匹配入口；Web 仅保持共享协议编译兼容。
