# 均衡拟人人机策略

## Goal

让机器人通过合法且不作弊的牌型评估持续优化手牌，能够真实胡牌，同时保持普通朋友水平的随机性，并将断线托管与机器人策略分开。

## Requirements

- 机器人策略只能消费自身暗牌以及桌面公开弃牌、公开组合、放赖牌、亮牌和剩余牌数。
- 策略不得接收其他玩家暗牌或牌墙顺序。
- 出牌候选需评估成组、对子、相邻/嵌张搭子、孤张和仍存在的有效进张；不得固定优先打回新摸牌。
- 候选相近时通过注入式随机源打破平局，确保测试可重放。
- 可胡时立即自摸；两张及以上赖子时优先放赖；碰与杠根据牌型和固定收益决定。
- TRUSTEE 响应阶段一律过，不采用完整 BOT 碰杠策略；主动阶段保留保守自动胡、放赖和弃牌行为。
- 自动动作仍通过现有权威 round reducer 执行，不复制合法性或计分逻辑。

## Acceptance Criteria

- [ ] AC1：新摸牌形成有效搭子且另有孤张时，机器人不会机械打回新摸牌。
- [ ] AC2：纯策略测试覆盖孤张、对子/搭子、公开牌耗尽、平分随机、碰/过、杠和多赖子。
- [ ] AC3：策略输入类型无法携带对手暗牌或牌墙顺序。
- [ ] AC4：服务测试证明 BOT 与 TRUSTEE 的响应策略不同，TRUSTEE 不自动碰杠。
- [ ] AC5：固定种子多局模拟中所有动作合法、牌局终止，并出现机器人胡牌。
- [ ] AC6：房间版本、持久化、隐私投影和既有玩家命令行为不变。
- [ ] AC7：引擎、服务定向测试以及全量质量门槛通过。
