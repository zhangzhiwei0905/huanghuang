# 签到活动与道具体系

## Goal

为游戏增加每周签到活动（周一至周日 7 天里程碑奖励），新增「签到页」与「背包（道具）页」，并扩展道具体系：

- **保星卡**（已有道具 `protection_cards`，新增签到获取渠道；UI 文案由「保护卡」统一改名为「保星卡」）
- **胡牌加倍卡**（新道具）
- **排位保护卡**（新道具，时限型、可叠加）

## Background（代码调研确认的事实）

- 现有保星卡机制（`packages/game-engine/src/competitive-rank.ts` `applyCompetitiveRankTransition`）：
  - LOSS 时自动消耗 `min(持有数, 掉星数)` 张，每张抵 1 星；黑铁/青铜/白银（majorIndex ≤ 2）完全免疫不耗卡。
  - 首次进入新大段赠送 `PROTECTION_CARDS_PER_NEW_MAJOR = 2` 张。
- 排位结算 `competitiveTerminalSettlement`（`apps/server/src/room-service.ts:967`）只在 `mode === "MATCH"` 时执行；单排与组队排位生成的对局房间都是 MATCH 模式，故道具对两者都生效。好友房（FRIEND）不做段位结算，不接入道具。
- 结算在回合特效转场完成时**同步提交**（`saveAcceptedTransition` 携带 `terminalSettlement`）；胡牌加倍卡需在此处插入限时决策环节。
- 星星数 = `competitiveMultiplierToLevel(multiplier)` ∈ 1..7；段位等级上不封顶，加倍后最多 +14 星无上限问题。
- 服务端 sqlite（`database.ts`）；客户端 Taro 小程序；排位功能要求微信绑定（`assertWechatLinked`）。

## Requirements

### R1 每周签到活动

- 周期：北京时间（UTC+8）每周一 00:00 重置；漏签不补；上周未领完的奖励过期作废。
- 签到动作：玩家在签到页点击「签到」按钮，同一自然日仅计一次。
- 奖励按「本周累计签到天数」里程碑自动发放，每个里程碑每周仅一次：

  | 累计天数 | 奖励 |
  |---|---|
  | 1 | 保星卡 ×1 |
  | 2 | 保星卡 ×3 |
  | 3 | 保星卡 ×8 |
  | 4 | 胡牌加倍卡 ×1 |
  | 5 | 胡牌加倍卡 ×2 |
  | 6 | 胡牌加倍卡 ×3 |
  | 7 | 排位保护卡 ×1 |

- 领取奖励时弹出说明弹窗，介绍所获道具的效果与使用方式。
- 签到要求微信绑定（与排位档案一致）。

### R2 签到页与背包页

- 首页单独入口进「签到页」：7 天签到格子 + 里程碑奖励展示 + 签到按钮；可补看本周已签/未签状态。
- 「背包页」挂在玩家信息下（类背包入口）：展示三种道具的剩余数量与效果说明；排位保护卡提供「使用」按钮与生效倒计时；保星卡与胡牌加倍卡仅展示（在对局中自动/按流程生效）。
- 图片素材由玩家后续提供；先用占位样式实现交互。

### R3 胡牌加倍卡

- 仅排位赛（MATCH）有效；玩家本局胡牌且持有 ≥1 张时，结算页前弹出限时弹窗：倒计时 10 秒选择「使用/不使用」，超时默认不使用并照常结算；其他玩家显示短暂等待提示。
- 使用后本局加星数 ×2（例：+4 星 → +8 星）；一局最多消耗 1 张；倍率不受 multiplier 枚举上限约束。
- 结算弹窗展示加倍效果（如「胡牌加倍 ×2」）。

### R4 排位保护卡

- 在背包页使用；每张 +2 小时生效时长；可叠加：`新到期时间 = max(当前时间, 现到期时间) + 2h`。
- 生效判定以**结算时刻**是否在有效期内为准。
- 生效期间排位输局：扣星数先减半（向下取整），再走保星卡自动抵扣。例：扣 3 星→减半 1 星→保星卡可再抵；扣 6 星→减半 3 星；扣 1 星→减半 0 星（不耗保星卡）。
- 低段位免疫（黑铁~白银）优先：免疫段位不扣星也不耗任何卡。
- 结算弹窗展示减半效果；背包页展示剩余有效时长倒计时。

### R5 命名统一

- 全部 UI 文案「保护卡」→「保星卡」（结算弹窗等现有位置）。

## Acceptance Criteria

- AC1 签到：北京时间周一 0 点后首次点击签到计第 1 天并发保星卡 ×1；同日重复点击不重复计；达到各累计天数自动发放对应奖励且每周每里程碑仅一次；周一重置后重新累计。
- AC2 签到说明：每次领取到奖励时展示道具效果说明弹窗。
- AC3 背包：三种道具数量实时正确（签到/升段/消耗后）；排位保护卡使用后到期时间按叠加规则延长并显示倒计时。
- AC4 加倍卡：排位胡牌且持卡时弹出 10 秒限时弹窗；选「使用」结算加星 ×2 且扣 1 张卡；超时或选「不用」照常结算不扣卡；好友房/非胡牌不出现弹窗。
- AC5 保护卡：有效期内的排位输局扣星减半（向下取整）后再抵保星卡；过期后恢复原扣星；结算弹窗展示减半。
- AC6 文案：游戏内不再出现「保护卡」字样（统一「保星卡」）。
- AC7 质量门：vitest 全绿、typecheck、lint、build:weapp 通过；后端改动部署线上，小程序重新编译。

## Out of Scope

- 好友房（FRIEND）不接入道具段位效果。
- 补签、签到连签额外奖励、道具赠送/交易/购买。
- 机器人不持有任何道具。
