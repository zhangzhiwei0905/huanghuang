# 优化结算赖子展示与听牌提示

## Goal

修复小程序结算弹窗中赖子牌左侧出现深色线条的视觉问题，并在玩家自己的出牌选择阶段主动标出所有“打出后可听牌”的手牌，帮助新手在确认出牌前了解不同出牌分别能胡哪些牌、对应胡牌类型、倍率与剩余数量。

## Background

- 小程序结算弹窗通过 `apps/miniprogram/src/components/RoundSettlementModal.tsx:80` 复用 `MahjongTile`，赖子牌由 `apps/miniprogram/src/components/MahjongTile.scss:35` 的外侧 `outline` 标识。
- 结算手牌在 `apps/miniprogram/src/components/RoundSettlementModal.scss:144` 使用负 `margin-left` 叠放；赖子牌的外侧轮廓伸入相邻牌区域，形成颜色较重的竖线。
- 当前小程序只在 `apps/miniprogram/src/pages/room/index.tsx:230` 维护选中的物理手牌 ID，并在 `apps/miniprogram/src/pages/room/index.tsx:713` 渲染自己的操作区；协议投影中没有听牌候选、胡牌类型或剩余数量。
- 胡牌判定权威实现在 `packages/game-engine/src/win.ts:185`，硬胡与软胡已经由同一套 `evaluateWin` 规则计算。
- `apps/server/src/room-service.ts:772` 为每个连接成员生成私有投影；这允许只为当前出牌者投影听牌指导，同时继续保持其他玩家暗牌为 `null`。

## Requirements

### R1 优化结算页赖子牌展示

- 结算弹窗内的赖子牌不再出现突兀的深色左侧线条。
- 赖子身份仍需清晰可辨，且不能破坏普通手牌的扇形叠放、完整可见性或结算弹窗布局。
- 不改变游戏内常规手牌、牌河或亮牌区域现有的赖子强调效果。

### R2 主动标出可听牌的出牌

- 在当前玩家进入任何合法出牌阶段时，预先计算每一张可打手牌对应的“打出后”听牌结果，包括正常摸牌、杠后补牌以及碰牌后未摸牌直接出牌的场景。
- 只要某张手牌打出后的候选列表非空，就在这张物理牌上方展示紧凑的“听”标识；相同牌种的多张物理牌都可正常点击和选择。
- 不会进入听牌的牌不显示“听”标识，但仍保持原有选择、二次点击出牌和其他动作交互。
- 赖子不可直接打出，因此赖子牌自身不显示“听”标识。

### R3 展开所选出牌的听牌卡片

- 点击带“听”标识的手牌后，该牌按现有交互进入选中状态，并在它的上方展示一张与所选牌关联的听牌卡片。
- 卡片内容只对应当前所选的出牌；切换到另一张带“听”标识的牌时，立即替换为该牌对应的候选结果。
- 选择不带“听”标识的普通牌时不展示听牌卡片；取消选择、出牌成功、回合变化或离开出牌阶段时清除。
- 每个候选项展示牌面、胡牌类型（硬胡或软胡）、合并后的预计胡牌倍数和剩余数量。
- 预计胡牌倍数等于胡型基础倍数（硬胡 2×、软胡 1×）乘以当前玩家个人倍数；不把其他三家的个人倍数混入该提示。
- 理论可胡牌即使剩余数量为 0 也继续展示，并明确标记“剩 0 张 / 已绝张”，不把它从候选列表隐藏。
- 候选牌按项目既有牌序稳定排列，避免重复展示同种牌。

### R4 赖子候选规则

- 赖子牌种默认必须作为听牌候选参与计算。
- 若“打出所选牌后的手牌”中仍持有赖子，则听牌候选中不展示赖子牌种。
- 赖子候选也必须通过与实际胡牌相同的权威规则判定，并展示准确的胡牌类型、倍数与剩余数量。

### R5 数据与规则一致性

- 听牌判定必须复用游戏引擎现有胡牌规则，不在小程序组件内复制麻将规则。
- 剩余数量只按公开信息计算：从四张同种牌中扣除当前玩家手牌、所有玩家公开的碰杠牌组/牌河/已放赖和亮牌中的同种牌。
- 不读取牌墙顺序、不扣除对手暗牌，也不通过结果间接泄露隐藏状态；这里的“剩余”表示玩家依据公开信息可推导的最多剩余张数。
- 现有出牌、胡牌、放赖、碰杠及结算行为保持不变。

## Acceptance Criteria

- [ ] 结算弹窗中无论赖子位于手牌首位、中间或末位，左侧都不出现异常深色竖线，赖子标识仍清楚。
- [ ] 玩家摸牌进入出牌阶段后，所有“打出后进入听牌”的物理手牌上方均显示紧凑“听”标识，其他牌不显示。
- [ ] 碰牌后未摸牌的出牌阶段也执行同样的提示规则。
- [ ] 点击带“听”标识的牌后，该牌正常选中，并在其上方展示只属于该出牌的候选卡片。
- [ ] 面板完整列出所有可胡牌，每项含牌面、硬胡/软胡、倍数和非负剩余数量。
- [ ] 选择不同手牌时结果立即更新；取消选择、回合或阶段变化后面板消失。
- [ ] 打出后手上没有赖子时，赖子牌种按实际规则出现在候选中；打出后手上仍有赖子时，赖子牌种不出现。
- [ ] 听牌结果与实际引擎胡牌判定一致，且不暴露其他玩家暗牌。
- [ ] 小程序类型检查、游戏引擎与相关服务测试、生产构建和格式检查通过。

## Out of Scope

- 改变硬胡、软胡、赖子、碰杠或计分规则。
- 为其他玩家展示听牌状态或暗牌信息。
- 自动替玩家选牌或出牌。
- 在本任务中同步改造 Web 端，除非后续明确要求。
