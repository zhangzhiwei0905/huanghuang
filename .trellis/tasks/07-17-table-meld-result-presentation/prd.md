# 牌桌组合与结算展示

## Goal

让本人的公开碰杠组合与其他玩家使用同一信息框展示，并将单局结算精简为每名玩家的最终手牌、倍率、本局和累计。

## Requirements

- 所有座位的公开组合统一显示在 `PlayerStation` 内；本人组合不得继续在底部手牌区单独渲染。
- 每个公开组合只渲染一次，最多四组时仍受玩家信息框和牌桌可视区域约束。
- 保留现有 SVG 牌面、碰杠落地反馈、两套主题、横屏手机和减少动态效果支持。
- 结算标题保留赢家与软/硬胡或流局状态。
- 删除结算上方独立倍率徽章、公式和付款人倍率卡片。
- 下方四名玩家分别展示最终暗手牌、个人倍率、明确标注的本局净变化和累计积分。
- 人机结算继续提供退出与继续游戏操作。
- 不修改协议字段、计分规则或持久化格式。

## Acceptance Criteria

- [ ] AC1：本人公开组合位于本人头像信息框内，且底部手牌区不再重复显示组合。
- [ ] AC2：本人最多四组公开组合时，桌面和 844×390 横屏下不越出玩家信息框或牌桌。
- [ ] AC3：低调与精美主题共用同一组件树，碰杠落地效果及 reduced-motion 行为保持正常。
- [ ] AC4：结算区域不存在上方倍率徽章、倍率公式和付款人倍率卡片。
- [ ] AC5：结算的四名玩家行均显示最终手牌、倍率、“本局”和“累计”。
- [ ] AC6：胡牌、流局和人机继续/退出的原有流程不受影响。
- [ ] AC7：组件测试、Web type-check 和生产构建通过。
